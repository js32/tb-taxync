TB-TaXync - Settings

Welcome to TB-TaXync

What does this extension do?

TB-TaXync synchronizes your Thunderbird labels (Tags/Keywords) between multiple computers and Thunderbird installations. This keeps all your email tags in sync everywhere.

How does it work?

  1. Export: Your tags are exported to a JSON file
  2. Save: The file is stored in a central location
  3. Sync: Other computers load the tags from there and import them

Sync Tools

You can use various synchronization solutions to sync the file between computers:

  • ⭐ Syncthing (recommended) - Decentralized, secure and private file sync between devices. No central servers required. This is the recommended solution!
  • Dropbox / Google Drive / OneDrive - Cloud storage
  • SMB Share - Network shares (NAS, Windows shares)
  • NFS - Network file system (Linux)
  • SSH/SFTP - Remote server access

Backups

Before every write, TB-TaXync automatically saves the previous version of your sync file into a .tb-taxync-backups folder right next to it (the last 30 versions are kept, older ones are pruned automatically). If a sync ever goes wrong, you can restore an older version from there manually.

Getting Started

  1. Choose a storage location for the sync file (e.g. ~/Sync/thunderbird-tags.json or /mnt/syncthing/thunderbird-tags.json)
  2. Configure a sync tool (Syncthing, Dropbox, SMB, etc.)
  3. Set the path in settings
  4. Start the first synchronization

💡 Tip: Under the "Settings" tab you'll find all options for configuring synchronization. In the "Logs" tab you can check errors and status.
